# Git密钥管理器

`Git密钥管理器` 是一个基于 `Tauri 2 + 原生 HTML/CSS + TypeScript + Rust` 构建的 Windows 桌面工具，用于管理 Git SSH 多账号配置、工作区绑定以及新仓库克隆流程。

> 当前版本：v0.1.3

## 项目简介

这个工具主要解决以下问题：

- 同一台电脑需要同时使用多个 Git 账号
- 同一平台存在多个账号，例如多个 GitHub 或多个云效账号
- 不同工作区或不同仓库需要绑定不同 SSH 身份
- 新仓库克隆时，希望直接使用指定别名和密钥，而不是手动改 remote

## 主要功能

- 管理多个 SSH 账号与密钥，自动写入 `~/.ssh/config`，支持同平台多账号（通过 `Host 别名` 区分身份）
- 扫描 `~/.ssh` 中已有密钥并复用；密钥表格化管理，支持创建密钥、一键复制公钥
- 解析 Git 地址，自动识别平台、域名、命名空间和仓库名
- 扫描工作区下的子 Git 仓库，按勾选结果批量绑定
- 一键刷新工作区，自动绑定其中新增的 Git 仓库
- 「快速导入」模式：输入地址、选择账号、自定义文件夹名，一键克隆并绑定
- 自动写入仓库的 `user.name`、`user.email` 和 `origin`（改写为 `git@别名` 地址）
- 启动时自动检查 Git 环境与 SSH 密钥，引导创建密钥
- 无边框窗口 + 自定义标题栏，功能菜单内置于顶部标题栏，右上角集成数据刷新，内置使用说明首页
- 提供 Windows 可运行的桌面构建物

## 技术栈

- 前端：原生 `HTML`、`CSS`、`TypeScript`
- 桌面框架：`Tauri 2`
- 后端能力：`Rust`
- 前端构建：`Vite`

## 本地开发

### 安装依赖

```bash
pnpm install
```

### 启动开发环境

```bash
pnpm tauri dev
```

### 构建前端

```bash
pnpm build
```

### 构建 Windows 程序

```bash
pnpm tauri build
```

构建产物通常位于：

```text
src-tauri/target/release/Git密钥管理器.exe
```

Windows 安装包（NSIS / MSI）位于：

```text
src-tauri/target/release/bundle/
```

## 使用说明

启动软件后会自动检查 Git 环境与 `~/.ssh` 密钥，并默认展示「使用说明」首页。顶部菜单包含：使用说明、快速导入、账号与密钥；标题栏右上角提供一键刷新数据。

### 已有仓库模式（账号配置）

1. 填写平台、Host 别名、密钥文件名、邮箱、Git 用户名
2. 选择工作区目录
3. 扫描子 Git 仓库
4. 勾选需要绑定的仓库
5. 保存账号并绑定工作区

### 新仓库模式（账号配置）

1. 填写平台、Host 别名、密钥文件名、邮箱、Git 用户名
2. 输入 Git 地址
3. 选择父目录
4. 保存账号并克隆新仓库

### 快速导入

1. 输入 Git 地址
2. 选择已管理的账号
3. 选择父目录并自定义文件夹名称
4. 一键克隆并自动绑定

### 密钥管理

1. 在「已有密钥」页创建新密钥，或复用 `~/.ssh` 中已有的密钥
2. 复制公钥并添加到 GitHub、云效、GitLab 等平台
3. 删除密钥会联动移除关联账号与 SSH config 块
